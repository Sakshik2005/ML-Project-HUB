# Machine Learning Projects Hub

A Flask-based web application that combines multiple Machine Learning prediction projects into a single dashboard. Users can select a project, enter input values, and get real-time predictions through an interactive web interface.

---

## Live Demo

🔗 https://ml-project-hub-fvyo.onrender.com

---

## Features

* House Price Prediction
* Customer Churn Prediction
* Diabetes Prediction
* Big Mart Sales Prediction
* Admission Prediction
* User-friendly dashboard interface
* Responsive design
* Machine Learning model integration using Flask
* Real-time predictions

## Installation Steps

### Clone Repository
git clone https://https://github.com/Sakshik2005/ML-Project-HUB.git


### Move to Project Folder
cd ML-Project-HUB


### Install Dependencies
pip install -r requirements.txt


### Run Application
python app.py


### Open Browser
http://127.0.0.1:5000

---

## Models Included

### House Price Prediction

Predict house prices using area income, house age, rooms, bedrooms, and population.

### Customer Churn Prediction

Predict whether a customer is likely to leave the company.

### Diabetes Prediction

Predict diabetes risk using medical and health-related parameters.

### Big Mart Sales Prediction

Estimate product sales based on outlet and product information.

### Admission Prediction

Predict admission chances using GRE, TOEFL, CGPA, SOP, LOR, and Research score.
